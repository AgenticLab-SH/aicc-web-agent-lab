# 미루 웹 미리보기

이 폴더는 미루 웹 작업본의 실행 파일 네 개를 옮긴 정적 프로토타입이다. 루틴 저장 키는 같은 값이 되도록 조합한다. 실행 명령은 [스냅샷 README](../README.md)에 있다.

- `data.mjs` 예시는 전부 합성이다. 루틴·날짜별 완료 체크는 이 주소의 브라우저 `localStorage`에 저장된다. 같은 브라우저의 같은 로컬 주소에 별도 이전 시험을 할 경우 새 격리 세션을 쓴다.
- 이 버전은 오늘 루틴과 원형·목록·완료 흐름을 보여 준다. 날짜 있는 일정의 Android 공통 상세, 고정/유연, WiZ·알람, 앱 데이터 이전은 이 웹 미리보기에서 작동하지 않는다.
- 프로토타입은 저장된 빈 목록을 열 때 예시를 다시 채운다. 원형 조각의 길이와 겹침 표현은 CSS 기반 개념 시각화다. 다음 구현의 기준 동작은 Android 모델과 신규 검수 항목을 우선한다.
