# 미루 웹 미리보기

`web-preview/`는 합성 데이터로 미루의 반복 루틴·날짜 일정·24시간 원형·시간순 목록을 확인하는 정적 미리보기다. [실행 절차](../README.md#커밋-zip에서-웹-미리보기-실행).

- 날짜 일정의 원형 호와 목록 행에서 같은 상세를 열어 이름·날짜·시각·고정/유연을 바꾼다. 자정을 넘는 일정은 두 날짜에 같은 ID로 나타난다. 정확히 00:00에 끝나는 일정은 시작 날짜에만 표시한다. 원형은 겹치는 시간대를 별도 궤도로 배치한다.
- 루틴 완료는 오늘 날짜에만 편집한다. 처음 열 때만 합성 예시를 채우며, 사용자가 지운 빈 목록은 새로고침 뒤에도 유지한다. 저장에 실패하면 편집 입력과 기존 데이터가 유지된다.
- 예시는 브라우저 `localStorage`에만 저장된다. 해당 주소와 브라우저 프로필을 바꾸면 저장 공간도 달라진다. 기상·조명·집중 카드는 체험용이며 실제 WiZ, Android 알람, 일정이 있는 기기·캘린더·외부 서비스 연결은 없다.
- 개발 검사는 `node --test web-preview/data.test.mjs`와 `node --check web-preview/main.mjs`로 실행한다. 사용자 흐름은 별도 격리 브라우저에서 시험한다.
