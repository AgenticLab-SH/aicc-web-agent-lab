# Native tray design
Keep lightweight WinForms and existing theme/high-contrast support. Use a fixed-height popup, top navigation, scrolling content and a persistent bottom toolbar. Keep numbered account order stable and preserve identity-based selection.
Use one blue accent for selected navigation/action, neutral surfaces and muted secondary information. Distinguish selected card, active route, paused account, missing quota and reauthentication. Buttons describe actions; progress never blocks the UI thread.
Choose the invocation monitor before layout. Position beside its taskbar, clamp all outer bounds to the work area, clamp manual moves and handle DPI/display changes. Data refresh and page changes do not reposition the window.
Update elapsed-time labels without sorting rows or relaying out every second. Stream account observations independently of slower connection probes; retained observations remain marked as old.

## Scroll and density revision
Use one content child inside the scroll viewport. Paint and interactive controls share this child's coordinates; never translate painting by viewport scroll offsets. Fixed navigation, selected-account toolbar and feedback footer remain outside scrolling. Account rows are 94 logical pixels; selected border and active-route stripe are distinct. Update elapsed text without repainting cards; relayout only for structural changes.

## Glass overview revision
Native WinForms monitoring flyout, retained for its existing small runtime; no new web engine or font download. Glass-inspired frosted surfaces with restrained white edge highlights; compositor-managed window corners and title material where supported. Opaque, sharp glyphs; no whole-window opacity. Follow Windows light/dark/high contrast and transparency preferences. Segoe UI Variable Text for body, Display for large quota numbers, native Korean font fallback.
Tokens: dark canvas #151B24 / surface #252D3A / text #EFF3F8 / muted #A6B4C5; light canvas #EDF2F7 / surface #FAFCFF / text #172331 / muted #566678; system accent. Spacing 4/8/12/16, radius 12 for account surfaces and 8 for buttons, hairline borders. No animation timers or screenshot blur.
Layout: fixed navigation | heading + four service states | two-column account comparison | policy summary | fixed selected-account actions | refresh/status footer. Single column when the work area is narrow; vertical scrolling preserves the one-surface coordinate model. No hidden hover-only primary information.
## Identity and legibility refinement
Identity: four connected account nodes around one command hub, enclosed by a frosted blue rounded square. No lettermark. Shared vector drawing source produces runtime tray icons, native window icon and multi-resolution ICO for executable/shortcuts. Optical simplification at small sizes; optional solid attention/ready dot plus textual tooltip, never animation.
Typography: Segoe UI Variable Text for native text with system Korean fallback; Segoe UI Variable Display for large numeric values. Secondary text 9.25pt, body 10pt, account heading 10.25pt, display quota 16pt regular. Explicit used/remaining captions, right-aligned figures; never change the meaning of a percentage silently. 100/110/120 percent text options; row geometry expands with text size. Preferences are owner-local, no new credential or route state.

Offline/uncertain outcomes preserve the draft and never replay a commit. Avoid raw numeric controls, giant empty list boxes, decorative gradients and duplicate account selectors.

## Glass and private labels - accepted refinement (2026-10-18 KST)
Operate surface: compare account usage immediately, then select one account for an explicit action. Existing WinForms tray utility, native title bar, fixed navigation/actions, one scrolling content plane. Preserve work-area/DPI clamping, keyboard selection, draft ordering, uncertain-mutation fences and exact identity hashes/selectors.
Visual anchor: cool frosted glass, restrained top-edge reflections, blue selection accent, bright quota figures and readable muted text. Native frame material where supported with subtle 96 percent window compositing; GDI foreground participates in this compositing. High contrast, remote sessions or disabled system transparency restore solid surfaces at full opacity. Persist Glass on/off with existing local display preferences. No screen capture blur, animation timer, new engine or polling.
Layout sketch: [Accounts | Connections | Auto switch | Pin] / [Usage + time zone; compact connection strip] / [two-column masked account comparison] / [threshold summary] / [one account selector; Use | Credits | Manage] / [Refresh | Settings; observation or actionable feedback]. Narrow work areas retain one column; window height follows content with a 680 logical-pixel cap. Routine navigation/selection is silent; warnings and mutation results remain explicit.
Account labels: keep numbered identity when present; mask the account portion to first grapheme + *** + last grapheme. One- and two-grapheme names expose only the first grapheme. Unknown names remain generic. Central presentation formatter covers cards, menus, pickers, order list, credit details, accessibility, tooltip, feedback and clipboard. Future accounts use the same path. Raw names never determine mutation targeting; identifiers and registry remain unchanged.
Reference pinned 2026-10-18: https://developer.apple.com/design/human-interface-guidelines/materials . Material is subordinate to legibility; preserve reduced-transparency and high-contrast behavior. Existing dependency stack retained. No automatic post-edit checks under current model policy; user explicitly requests actual installation.

## Existing-owner tools integration - accepted scope
Keep the current glass, masking, pinned opening and compact account comparison. Surface pause/resume directly in the one selected-account action bar; remove its duplicate menu entry. Preserve the existing exact-identity preview/commit manager, dispatch lock and result reconciliation. Pausing excludes an account from new automatic selection; it is not an inferred cancellation of an already dispatched request.
Navigation: Accounts / Connections / Auto switch / Tasks / Tools. Tasks reads the existing continuity helper only on demand, retains dated observations on failure and opens the existing management dialog for all registration/resume actions. No second task registry, scheduler or sender. Capability/unknown state remains explicit. Tools offers precise entry points to official OCX accounts/strategy, usage, logs, models, providers and installed-version dashboard, plus the existing AICC manager, phone pairing and masked diagnostic copy. Full editing/history stays with its owner; no duplicate strategy/config engine or log store.
Use fixed allowlisted OCX hash routes through the existing owner-verified dashboard launcher. Existing tunnel, browser choice and authentication remain intact; missing management binding fails without starting a tunnel, using a different account or switching routes. Native Codex quota/goal are not guessed from OCX or AICC state. Version information is read from existing component registration; no upgrade/rollback action or automatic restart is added.
All commands run off the UI thread with a single in-flight guard and bounded output/timeouts. On-demand read snapshots use a 60-second cache; failures preserve earlier values visibly. No new polling timer, animation, credential copy or raw diagnostic log display. Current model policy excludes automatic post-edit checks; build/install are explicitly authorised by the user. Source, installation receipts and unexecuted UI checks remain separate.

Reuse optional bundled continuity UI through its existing type, with a safe existing-manager fallback. No mandatory dependency on another writer's untracked dialog source.
## Text integrity and bounded repaint - accepted repair 2026-10-18 KST
Treat task title corruption and scroll text trails independently. A pre-edit redirected-child byte diagnostic established code page 949 output (C7D1B1DB for Korean sample) versus the caller's UTF-8 contract (ED959CEAB880). Registration titles contained no U+FFFD. Configure only the invoked PowerShell child's console/output encoding before calling the unchanged pinned helper, and decode both streams with strict UTF-8. Share this boundary with the existing optional continuity dialog. Do not edit registered titles, helper protocol/hash, global code page or worker identity.
GDI TextRenderer helpers and owner-draw controls preserve Graphics clipping; transformed helpers also preserve translation. The opaque buffered canvas fills the invalidated region before Paint, intersects/restores Graphics state and invalidates content on scroll. No polling/repaint timer or new render host. Display truncation keeps grapheme boundaries. This implementation is not independently visually verified.
Reusable repair rules are routed by windows-design to references/winforms-text-boundaries.md; common directives contain only a compact boundary rule. Canonical guidance remains the owner; deploy via existing Codex-specific tools and retain refused legacy content.
