# 웹 GPT GPT 그룹 탭 이어가기

사용자가 만든 Chrome 탭 그룹 `GPT` 안의 지정 ChatGPT 탭 7개를 5분마다 확인한다. 오류나 30분 이상 확인된 정체가 있을 때만 사용자가 정한 재개 문구로 이어간다.

## 대상

매 실행에서 Chrome 그룹 이름 `GPT`와 각 ChatGPT URL의 conversation ID를 확인한다.

1. 해커톤 분석 정리 — `00000000-0000-4000-8000-000000000000`
2. skct 총괄 — `00000000-0000-4000-8000-000000000000`
3. 웹쫀쿠 총괄 — `00000000-0000-4000-8000-000000000000`
4. 개발자산 프로젝트 포폴 관리자 — `00000000-0000-4000-8000-000000000000`
5. 자동매매 총괄 — `00000000-0000-4000-8000-000000000000`
6. 제미나이 전환 검토 — `00000000-0000-4000-8000-000000000000`
7. 채용지원 — `00000000-0000-4000-8000-000000000000`

그룹 소속이나 일곱 ID를 확인하지 못하면 조작하지 않고 멈춘다.

## 운영 범위

- AICC는 주기·정체 기준·재개 문구를 설정하는 GUI와 로컬 저장 API를 제공한다.
- Codex skill은 사용자 탭을 읽고, 필요할 때 지정 문구로 재개한다.
- 감시 규칙은 Web GPT에 보내지 않는다. 사용자가 정한 상황 문구만 전송한다.
- 실행 영수증에는 대화 본문·URL·composer를 저장하지 않는다.
