# GPT 그룹 7개 탭 감시 및 재개

## 기능 요구사항

- Chrome 탭 그룹 `GPT`에 지정된 기존 ChatGPT 대화 7개만 감시한다.
- 각 탭을 5분마다 확인한다. 사용자는 AICC GUI에서 5분 단위로 간격을 바꿀 수 있다.
- 기본 정체 기준은 30분이다. 사용자는 5분 단위 기준을 바꿀 수 있다.
- 기본 완료, 전송 시간 초과, 복잡성 개선 문구를 화면에서 고치고 저장할 수 있다.
- 그룹 이름이나 ID, 현재 대화 상태를 읽지 못하면 전송·새로고침·중지하지 않고 HOLD한다.
- `메시지 전송 시간이 초과되었습니다. 다시 시도해주세요`가 보이면 오류 문구를 보낸다.
- `연결이 끊어졌습니다. 전체 답변을 기다리는 중입니다`가 보이면 입력란이 빈지 확인한 뒤 한 번 새로고침한다.
- 30분 동안 답변 진행이 없고 생성 표시와 중지 버튼이 확인될 때 해당 탭을 중지한 뒤 기본 재개 문구를 보낸다.
- 전송 직전에 대화 ID와 빈 입력란을 재확인한다. 전송 여부가 불확실하거나 초안이 있으면 다시 보내지 않는다.
- 영수증에는 그룹명, 탭 ID, 상태, 시각, 진행 지문만 저장한다. 본문·URL·composer 내용은 저장하지 않는다.
- 브라우저 상태를 읽지 못한 실행은 성공 영수증으로 남기지 않고 heartbeat를 켜지 않는다.

## AICC 화면 기준

- 감시 켜기/끄기, 5~60분 간격, 10~180분 정체 기준을 제공한다.
- 세 가지 사용자 지정 재개 문구를 저장하고 다시 읽는다.
- 설정 저장 상태와 최근 실제 실행 영수증을 분리해 보여준다.
- 작은 화면과 키보드만으로 주요 설정을 사용할 수 있어야 한다.

## 검증 기준

| 항목 | 통과 증거 |
|---|---|
| 탭 신원 | Chrome 화면에서 그룹명 `GPT`와 일곱 conversation ID가 한 번씩 확인됨 |
| 재개 흐름 | 완료·전송 오류·연결 끊김·30분 정체·복잡성 분기 및 중복 방지가 확인됨 |
| AICC 저장 | 폼 저장·재읽기·잘못된 값 거부·기존 파일 보존 |
| 화면 | 반응형·키보드 접근성의 실제 브라우저 확인 |
| 스킬 | AICC 원본과 Codex 설치본 일치, validator 통과 |
| 운영 | 중복 없는 단일 예약과 일곱 탭의 첫 실행 영수증 |

## 안전 경계

탭 그룹 구성, 다른 탭, 로그인, 계정, 권한, 결제는 변경하지 않는다. 이전 영수증은 보존하되 현재 그룹 신원의 증거로 재사용하지 않는다. 잘못된 설정 파일은 자동으로 덮지 않는다.
