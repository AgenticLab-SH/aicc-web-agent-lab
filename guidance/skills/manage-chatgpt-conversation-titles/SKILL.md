# 지피티 채팅 제목 관리

사용자가 이 작업을 명시적으로 요청할 때만 사용한다. 일반 대화를 시작했거나 제목이 모호하다는 이유로 실행하지 않는다. 예약·자동화·백그라운드 정리를 만들지 않는다. 제목 변경 요청과 실제 실행 시험 승인은 그 범위의 변경을 허용하며 매 항목마다 재승인을 묻지 않는다. 후보 미리보기만 요청했다면 변경하지 않는다.

## 대상과 내용 읽기

1. 사용자 지정 계정·workspace와 대상을 결속한다. 기간은 기본 **작성일의 KST 날짜**다. 수정일을 요청한 경우에만 수정일로 검색한다. 날짜만 준 종료일은 해당 날짜 말까지 포함한다. 작성일 미상 항목을 수정일로 대신 포함하지 않는다. 제목 조건은 사용자가 말한 텍스트의 literal 포함 여부다. 기간과 제목을 함께 주면 별도 지시가 없는 한 둘 다 만족하는 대상으로 좁힌다. 검색 상한·누락·날짜 미상은 따로 보고한다.
2. stable 대화 ID·현재 제목·작성/수정일과 포함 사유를 기록한다. 같은 제목의 다른 대화를 합치지 않는다. 대화 제목에 Project 이름 접두사 w-/l-를 강제하지 않는다.
   지정 ID는 해당 대화만 조회한다. 한 대화를 찾으려고 계정 전체·모든 Project 목록을 훑지 않는다. 제목·날짜 검색의 제한된 결과에는 전수 여부를 표시하며, 실제 HTTP 429는 안전한 Retry-After와 원 요청 상태를 보존한다. 실패한 목록 읽기를 자산 변경 성공 또는 사용 한도 배너로 해석하지 않는다.
3. **Web GPT 자체 능력을 먼저 사용한다.** 현재 대화 문맥 또는 실제 노출된 대화 검색·읽기 도구로 내용을 읽는다. 요약된 문맥과 전체 원문, 미열람 첨부를 구분한다. 도구가 없거나 필요한 본문이 부족할 때만 기존 `chatgpt-conversation-import`의 로컬 읽기를 AICC로 요청한다. 로컬 파일 생성은 Web가 읽었다는 증거가 아니므로 필요한 본문을 실제로 읽고 read scope를 남긴다.
4. 일반 Chat·요청된 xhigh를 유지한다. AICC `list → open → exec/read → close`의 실제 capability를 사용한다. Web 컨테이너는 사용자 PC가 아니다. 명령이 없거나 격리·권한에 막히면 부족한 capability와 오류를 남긴다. RDC나 다른 계정·도구를 보안 거절의 대체 경로로 쓰지 않는다. AICC의 codex_task_set_title은 로컬 Codex 제목용이며 Web 채팅 제목 도구로 쓰지 않는다.

## 제목 결정과 변경

읽은 내용의 주제·목적·산출물을 나타내는 짧은 제목을 만든다. 단순히 첫 질문을 반복하거나 해결되지 않은 일을 완료했다고 쓰지 않는다. 비밀·민감 식별자를 새 제목에 넣지 않는다. 근거 본문이 부족한 항목은 건너뛰고 이유를 기록한다.

지원되는 지피티 자체 제목 변경이 있으면 사용한다. 로컬 실행이 필요하면 기존 private adapter의 `REGISTERED_PRIVATE_ADAPTER_ROOT/scripts/chatgpt-conversation-titles.mjs`를 사용한다. 정확한 계정/workspace·대화 ID·현재 제목·원하는 제목·읽기 증거를 결속한다. 변경 직전 같은 ID의 제목을 다시 읽고, 이미 원하는 제목이면 재저장하지 않는다. 다른 작성자가 제목을 바꿨으면 기존 요청 결과부터 조정한다.

변경 전 old/new·본문 읽기 범위·대화 ID를 로컬 durable journal에 기록한다. 제목 변경은 복원용 old title을 보존하되 대화 본문을 GitHub·Notion에 새로 올리지 않는다. 이 스킬 자체의 생성·수정은 공통 GitHub/Notion 자산 백업 절차를 따른다. 지원 UI에서 한 번 저장하고 같은 ID를 다시 읽어 실제 제목을 확인한다. 불명 저장은 자동 재발신하지 않는다. 대화 내용·Project·pin·archive·공유 설정은 변경하지 않는다.

[로컬 실행 계약](references/executor.md)은 해당 실행 경로가 필요할 때만 읽는다. 결과에는 실제 바뀐 old → new, 건너뛴 항목·읽기 범위·검색 누락을 짧게 보고한다. Web 직접 실행과 Codex 대행은 구분한다.
