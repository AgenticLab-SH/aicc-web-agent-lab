# 학습과 포트폴리오 근거 게이트

## 근거 우선순위

1. 공식 요구사항, 평가 기준과 원본 자료
2. 현재 코드, 데이터, 설정과 재현 가능한 명령
3. 테스트, 로그, 수치, 스크린샷과 렌더 결과
4. 당시 작성한 사용자 노트와 결정 기록
5. AI 설명과 사후 회상

낮은 순위의 근거가 높은 순위와 충돌하면 확정 문장으로 합치지 않는다. `UNKNOWN`, `재현 필요`, `사용자 확인 필요` 중 알맞은 상태를 남긴다.

## 학습 기록 질문

- 처음 무엇이 이해되지 않았는가?
- 어떤 원문, 코드 또는 실험을 확인했는가?
- 실행 전에 무엇을 예상했는가?
- 어떤 값, 오류 또는 동작을 실제로 관찰했는가?
- 결과 때문에 설명이나 판단이 어떻게 바뀌었는가?
- 다음 과제나 현업 결정에 어떤 기준으로 적용할 것인가?

## 포트폴리오 승격 질문

- 결과가 현재 코드와 실행에 연결되는가, 문서에만 적혀 있는가?
- 실패와 수정이 원인, 조치와 재검증으로 이어지는가?
- 수치의 단위, 조건과 비교 기준을 설명할 수 있는가?
- 팀 산출물에서 본인 기여를 분리할 수 있는가?
- 면접에서 원본 근거를 다시 열어 재현할 수 있는가?

중대한 공백이 하나라도 있으면 상위 상태로 승격하지 않는다.
