# 근거 중심 보고서체

`근거 중심 보고서체`는 사실, 수행, 관찰, 해석과 한계를 구분하는 전문 한국어 보고서 문체다.
기본 종결은 자연스러운 `-습니다`체이며, 문서 목적과 공식 양식이 다른 종결을 요구하면 그 양식을
우선한다.

## 원칙

- 독자가 첫 문단에서 목적과 현재 결론을 파악하게 한다.
- 추상적인 평가보다 무엇을 수행했고 무엇이 나왔는지 쓴다.
- 숫자, 날짜, 고유명사, 부정, 조건과 책임 주체를 바꾸지 않는다.
- 수치를 제시한 뒤 무엇을 뜻하고 무엇까지는 뜻하지 않는지 적는다.
- 사실·관찰과 작성자의 해석·제안을 같은 문장에 섞지 않는다.
- 실패, 미검증, 불확실성과 반례를 결과에서 숨기지 않는다.
- 직접 경험이 중요하면 `저는`, `제가`를 사용할 수 있지만 문장마다 반복하지 않는다.

## 권장 전개

문서 목적에 필요한 역할만 사용한다.

1. 목적 또는 확인할 질문
2. 수행·분석 방법과 범위
3. 관찰한 결과와 근거
4. 결과의 해석과 예상과 다른 점
5. 제한, 결정, 다음 조치 또는 남은 질문

모든 문단을 같은 길이와 구조로 맞추지 않는다. 중요한 판단은 충분히 설명하고 단순 완료 사실은
짧게 쓴다. 문단마다 교훈이나 요약을 붙이지 않는다.

## 표현 기준

다음처럼 구체적으로 쓴다.

- `성능이 크게 향상됐습니다`보다 `평균 응답 시간이 420 ms에서 280 ms로 줄었습니다`라고 쓴다.
- `검증을 완료했습니다`보다 `20건을 같은 조건으로 재실행했고 20건 모두 통과했습니다`라고 쓴다.
- `문제가 있었습니다`보다 증상, 확인 위치와 영향을 쓴다.
- `적용할 수 있습니다`라고 쓸 때는 실제 적용과 제안·가정을 구분한다.

반복하거나 근거 없이 사용하지 않는다.

- `이를 통해`, `결론적으로`, `요약하자면`으로 모든 문단을 닫는 방식
- `혁신적`, `탁월한`, `완벽한`, `성공적인`, `효율적인`
- `역할을 분명히 했습니다`, `기준을 남겼습니다`, `증거로 남겼습니다`
- 실행하지 않은 미래 상태를 현재 완료로 쓰는 표현
- 자동 지표 상승을 정확성·안전성·업무 효과와 동일하게 취급하는 표현

## 보고서 유형별 조정

- 기술·실험: 설정, 실행 조건, 결과, 오류 분석과 재검증을 명확히 쓴다.
- 분석·의사결정: 결론, 근거, 대안, 위험과 권고를 앞에 둔다.
- 프로젝트·상태: 완료, 진행, HOLD, 책임자와 다음 기한을 구분한다.
- 학습·회고: 처음의 질문, 확인한 단서, 이해가 바뀐 이유와 다음 질문을 실제 순서로 쓴다.
- 조사: 확인된 사실, 출처, 추론과 미확인을 구분한다.

## 최종 검수

- 사실과 수치가 원본 근거와 일치하는가?
- 부정·조건·범위·책임 주체가 바뀌지 않았는가?
- 관찰하지 않은 결과나 서비스를 만들지 않았는가?
- 같은 의미의 문장을 요약·본문·결론에서 반복하지 않았는가?
- 작성자의 판단과 출처의 주장을 구분했는가?
- 다음 조치가 있다면 대상, 시점과 완료 기준이 드러나는가?
