# Windows 웹 스택 동작과 모션

모션은 화면 장식보다 상태 변화의 원인과 결과를 보여주는 데만 쓴다. 새 창·트레이·상태 갱신·대규모 목록에서는 짧고 안정된 동작을 우선한다.

- 클릭/키보드 포커스: 즉시 반응해야 한다. 상태 변화는 toast, 스피너, progress, 완료 표시 중 하나로 전달한다.
- 진입 애니메이션: 복잡한 parallax와 반복 확대 대신 120~220ms 범위의 짧은 전환을 기본 후보로 검토한다. 이 수치는 기본 제안이지 필수 사양이 아니다.
- prefers-reduced-motion에서는 필수 정보 유지, 과도한 이동·페이드 제거, 상태 알림 텍스트 보존을 확인한다.
- 차트·목록 동적 갱신은 사용자가 읽던 행/스크롤/선택과 입력 포커스를 유지한다.
- 버튼에 연결된 진짜 실행 작업과 데모용 모션을 구분한다. 실행 완료 전에 성공 애니메이션을 보여주지 않는다.

검증: 저사양 PC, 배터리 절약 모드, 키보드 전용 조작, 반투명/불투명 전환과 창 닫기 중 예외 발생 여부.
