# 웹 시각 레퍼런스의 적용 한계

Awwwards 등 수상작의 화면은 제품 브리프를 위한 참고 자료이지 Windows 도구의 필수 디자인 기준이나 사용 허가를 받은 소스가 아니다.

## 적용 기준
1. 레퍼런스에서는 정보 위계, 그리드, 타이포 대비, 장면 전환 원리만 추출한다. 타사 그래픽·원본 소스·브랜드 자산을 허가 없이 복제하지 않는다.
2. 도구 화면은 정확한 상태, 지연 시간, 키보드 조작, 네트워크 장애 대응이 우선이다. 분위기 연출은 핵심 사용성 검증 이후에만 추가한다.
3. 작은 모니터·원격 데스크톱·고배율·저사양 Windows에서도 작업 완료가 가능해야 한다. 크고 무거운 자산은 지연·오프라인 대체 표현을 제공한다.
4. WPF/WinUI는 OS 고유 접근성과 창 동작이 먼저이며, Tauri/Electron은 WebView/Chromium 차이를 명시한다.
5. 반응형 확대·반투명·blur·3D 효과는 화면 캡처와 실제 메모리·CPU 사용량을 비교해 선택한다.

승인된 사용자 소스가 없다면 공개 레퍼런스를 찾아 사용하지 않고 원리 설명만 재사용한다.
