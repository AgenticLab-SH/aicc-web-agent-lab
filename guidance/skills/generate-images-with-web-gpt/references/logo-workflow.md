# 로고와 브랜드 키트 제작 계약

## 브리프

생성 전에 브랜드명과 정확한 표기, 대상 사용자, 약속, 성격, 금지 연상, 기존 mark, 사용
환경, 최소 크기, 배경색, 필요한 산출물을 확인한다. 모르는 제품 사실을 로고 서사로 만들지
않는다.

## 방향과 생성

1. symbol, wordmark, combination mark 중 필요한 유형을 정한다.
2. 사용자가 지정한 시안 수와 현재 도구 계약에 맞춰 서로 다른 방향을 독립 이미지로 생성한다. 한 contact sheet 안의 작은 후보만으로
   선택하지 않는다.
3. 정확한 문자가 핵심이면 wordmark text를 verbatim으로 적고 결과 글자를 직접 검사한다.
4. 선택 후보를 full color, single color, inverse, 16~32px favicon 규모에서 확인한다.
5. 유사 상표·기존 유명 로고·브랜드 고유 형상을 검색 없이 “독창적”이라고 확정하지 않는다.

## 산출물

승인된 master에서만 favicon, app icon, social avatar, light/dark 배경, 가로/세로 lockup,
간단한 color/type note를 파생한다. raster 이미지를 확장자만 바꿔 SVG라고 부르지 않는다.
벡터 납품이 필요하면 geometry와 path를 별도로 재작성하고 확대·단색·윤곽을 검증한다.

이 흐름은 `Nutlope/logocreator`의 brand-brief → variants → brand-kit 제품 흐름을 pattern으로
참고했다. 검토 당시 저장소에 license 파일이 확인되지 않아 코드·UI·asset은 복사하지 않았고,
Together AI·Clerk·Upstash도 도입하지 않았다. AICC의 기존 인증된 이미지 생성 경로를 유지한다.

검토·렌더 확인은 현재 모델 정책과 명시적 요청이 허용하는 범위에서만 수행한다. 실행하지 않은 문자·크기·단색·윤곽 확인은 NOT_RUN이며 산출물 생성과 구분한다. 이 참조만으로 이미지 도구 사용 가능 여부나 법적 사용 가능성을 확정하지 않는다.
