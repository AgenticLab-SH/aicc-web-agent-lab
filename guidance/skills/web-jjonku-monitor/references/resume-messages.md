# 재개 문안

현재 선택 감독기는 다음 문구만 사용한다: `하던 작업 중단 지점부터 재개해`. 아래 문안은 명시적 레거시 그룹 방식에만 적용한다. 시간 초과 자체를 재전송 허가로 해석하지 말고 원래 결과를 먼저 회수한다.

대화 composer가 비어 있고 정확한 대상 대화를 확인한 뒤, 상황에 맞는 문안 하나만 보낸다. 줄바꿈과 문구를 바꾸지 않는다.

## 계속

```text
작업을 계속하면 돼.

작업 단위는 중간 보고 단위 5개마다 최종 보고를 하여 대화를 종료해.

그 다음 사용자 지시를 받으면 작업을 지속하면 돼.
```

## 오류 재개

```text
'메시지 전송 시간이 초과되었습니다. 다시 시도해주세요'라는 문구가 떴어. 주의하면서 작업을 계속하면 돼.

작업 단위는 중간 보고 단위 5개마다 최종 보고를 하여 대화를 종료해.

그 다음 사용자 지시를 받으면 작업을 지속하면 돼.
```

## 복잡성 개선

```text
명칭들을 다 개선하자. 명확하고 지속가능한 명칭으로 모든 문서와 코드의 명칭을 개선하고 시작하자. 복잡성을 개선하고, 정리를 잘 해두고 재개하자. 삭제하지말고 보관처리를 하도록 해. 너무 큰 용량은 판단해보고 삭제해도 돼. 삭제 실수를 하면 안되니까 정확하게 그 파일을 해.
```
