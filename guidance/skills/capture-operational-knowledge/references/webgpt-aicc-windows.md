# Windows WebGPT와 AICC 역사 기록의 사용 범위

이 참조의 이전 내용은 2026-09-19 운영 관측과 2026-10-10 자산 정리 기록이었다. 당시 계정 번호·CDP 포트·기본 모델 경로·플러그인 ID·도구 수·설치 경로는 현재 구성 계약이 아니다. 개인 원본과 영수증 위치는 소유자의 활성 스킬 밖 백업 및 프로젝트 정본에 보존한다. 공유 core에는 해당 개인 값을 복제하지 않는다.

2026-10-16 KST 문서 이관으로 적용 범위를 정리했다. 현재 inventory·health·로그인·런타임을 새로 조사한 기록은 아니다.

- 현재 작업의 context/PROJECT.md와 기존 등록 정보를 먼저 읽는다. 계정은 실제 로그인 신원, 모델 경로는 요청 상관 근거로 판단하며 포트·이름·목록 순서로 추정하지 않는다.
- 경로 변경은 manage-codex-model-routes, Workspace 작업은 aicc-workspace-operator, Web 관제는 web-gpt-driving의 기존 계약을 따른다. 이 문서를 이유로 현재 정상 구역을 일괄 검사하거나 재시작하지 않는다.
- 옛 health/ready·시작 요청·설치 영수증은 해당 단계의 역사 근거다. 현재 추론 경로·native 호출·사용자 완료를 대신하지 않는다.
- 불명 전송은 기존 결과 조정부터 한다. 잠금/프로세스 소유권·현재 미결이 불명하면 강제 종료·잠금 제거로 진행하지 않는다.
- 일반 목록 실패를 빈 inventory로 단정하지 않는다. 프로젝트 멤버십, 루트/보관 목록, 본문 읽기, 파일 바이트, 실제 도구 호출은 각각 근거 범위를 기록한다.
- 프로젝트 자산 이동의 상세 소유자는 manage-chatgpt-assets/references/conversation-migration-contract.md다. 기존 로그인·프로필·원본과 담당을 보존한다.

반복 장애를 다룰 때는 [작은 사례 색인](문제와-해결책/색인.md)에서 관련 항목만 연다. 과거 성공 절차를 현재 실행 권한이나 보안 차단 우회 근거로 사용하지 않는다.
