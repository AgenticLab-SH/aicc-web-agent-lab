# 반환 형식과 의미 판단

- 판정: 채택. 정규 반환 형식과 문맥으로 판단하는 경계다. classifier 수정 전체의 검증 판정은 아니다.
- 증상/범위: 첨부 조회가 입력 태그/ID와 다르거나, 단어 후보가 실패·완료로 잘못 분류됨.
- 원인: 첨부 반환이 정규 이미지 참조로 바뀔 수 있다. whole-reply 정규식이 서로 다른 문맥을 연결했고 부정·행동 주체를 놓친 오판이 관측됐다.
- 대안 비교: 원래 태그/ID 강제 일치는 재업로드를 유발한다. 키워드 개수만 늘리면 문맥 오판이 남는다. 정규 참조·파일명과 최신 요청/응답의 의미를 좁게 대조하는 방식은 불필요한 재전송과 긴 원문 복제를 줄인다. 더 정교한 parser는 구현·검증 전까지 후보일 뿐이다.
- 최소 절차: [첨부의 정규 참조](../../../web-gpt-driving/references/failure-solutions.md#notion-첨부의-정규-참조와-원본-보존)와 같은 파일의 ‘단어 후보와 실제 실패·완료의 뜻을 구분’을 적용한다. 단어 일치는 후보로만 두고 결과 의미를 짧게 기록한다.
- 중단/갱신: 지원 형식이 불명하거나 본문을 읽지 못하면 UNKNOWN. 같은 SHA는 내용 결속이며 승인이나 의미를 대신하지 않는다. 새 반환 형식/반례는 기존 카드를 갱신한다.
