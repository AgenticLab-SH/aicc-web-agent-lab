# AICC 대시보드 제품 명세

## 공통 제어 화면

Windows 트레이의 **AICC 앱 열기**와 **공통 도구 열기**는 등록된 운영 앱의 전체 현황과 공통 도구로 연결됩니다. Windows 상태 창은 빠른 상태와 복구를 제공합니다. 등록한 로컬 앱에 연결할 수 없으면 이 상태 창에서 문제 해결을 사용합니다.

웹앱과 Windows 트레이 진입점은 전체 현황, 내 앱, AI 보고, 지시·목표, 설정의 다섯 주 메뉴를 공유합니다. 계정·한도, 정책·경고, 기기, 협업, 기존 대화와 PC 실행 기능은 공통 도구에서 찾습니다. PC에서만 가능한 기능은 그 이유와 Windows 메뉴를 표시합니다.

## 내 앱과 설치

앱 표시 이름은 AICC입니다. 내 앱에서 최근 연 앱을 최대 세 건 표시합니다. 저장한 것은 브라우저별 앱 ID입니다. 현재 등록 목록을 기준으로 이름·주소·상태를 읽습니다. 웹 열기·PC 전용·주소 미등록·사용 종료는 문구로 구분합니다. 조회가 실패하거나 일부 자료를 못 읽으면 마지막 확인 목록을 유지하고 재조회할 수 있게 합니다.

Android 런처 및 웹앱 이름은 AICC로 통일합니다. 웹 설치는 원 PWA ID와 시작 주소를 유지하며 Android는 기존 패키지 ID와 동일 서명으로 버전을 올립니다. 설치 안내에 ‘웹에서 열기 · 내 앱’과 ‘Android 설치·업데이트’를 표기합니다. 업데이트 시각은 배포 manifest에 결속합니다. 폰에 설치된 버전이나 실제 앱 업데이트 성공을 서버 다운로드 응답만으로 표시하지 않습니다.

## 인증과 실행

- 기존 PC 소유자 세션과 등록 기기는 같은 보호 API를 사용합니다. 원래 로그인·저장·보호 범위를 유지합니다. 현재 브라우저에서 연결과 기기 상태를 확인합니다.
- 변경은 대상과 권한 확인 → 미리보기 → 단회 확인 → 기존 실행기 → 원 요청 결과 조회 순서입니다. 예시 스냅샷은 실제 호스트 실행권을 부여하지 않습니다.
- PC 창 요청 접수, 실제 표시, 전달 ACK, 새 작업, 완료를 구분합니다. 결과 불명은 원 작업을 조회하며 재전송하지 않습니다.
- 계정·상한·자동재개는 등록된 원 계약을 유지합니다. 준비 상태, 발신 권한, 적용 여부가 확인되지 않으면 조작 가능한 상태로 표시하지 않습니다.
- 전체 현황과 보고는 읽기 전용 원장을 투영합니다. 각 시각은 기록 기준과 관측을 구분합니다.

## 확인 기준

320/360/768px와 데스크톱에서 주요 이동, 키보드, 로딩·빈값·오류·실패 후 보존을 확인합니다. 설치/인증/변경 작업의 실제 승인과 운영 전환은 별도 결과로 기록합니다. 공개 작업 검증은 [합성 환경](web-agent-lab.md)으로 수행합니다.
