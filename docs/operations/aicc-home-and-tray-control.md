# AICC 홈과 Windows 트레이

- Windows 트레이에서 기존 AICC 앱의 전체 현황과 공통 도구를 엽니다. 별도 PC 상태 창에는 복구와 Windows 전용 항목이 있습니다.
- 조회, 미리보기, 단회 확인, 원 결과 조회를 구분합니다. 결과가 불명확하면 기존 작업의 상태를 읽고 재실행하지 않습니다.
- 공개 작업본의 브라우저 미리보기는 합성 상태만 사용합니다. Windows 복구, 로그인, 계정 전환, 서명 및 알림 전송에는 등록된 운영 주체가 필요합니다.
