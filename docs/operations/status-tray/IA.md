# 정보와 조작 정본

왼쪽 트레이 클릭 → compact 상태 창. 오른쪽 트레이 메뉴는 열기/종료 두 항목만 제공한다.

창 하단: 새로 고침(F5/Ctrl+R), 설정(Ctrl+,). 계정별 전환은 해당 행에서만 제공하며 현재 선택 계정에는 전환 버튼을 숨긴다. 계정 더보기는 중지/재개·우선순위·초기화권·자동 선택을 제공한다. 전환은 더보기에서 중복하지 않는다. 창 고정은 상단 아이콘에만 둔다.

설정 메뉴는 한도 정책, OCX 관리 화면, Slack 한도 대화, 반영 확인, 화면 갱신 주기, 투명 배경, 상태 복사(Ctrl+Shift+C), 설명서를 한 번씩 제공한다. 반영 확인은 미확인 변경이 있을 때만 활성화한다. 한도 정책 변경은 지원 정책과 변경 잠금을 확인한다. 초기화권 미확인은 소비 버튼을 활성화하는 근거가 아니다.

조회 실패는 연결 단절과 구분하고 캐시 관찰 시각을 표시한다. 명령 중에는 계정 조작을 막되 안전한 결과 확인은 불확실 상태에서도 허용한다. 갱신 중지/숨김은 한도 보호를 끄지 않는다. 초기화권 확인·physical ID·single writer·no ambiguous retry는 기존 제어 경로를 유지한다.
## 공통 웹 화면 탐색
계정·한도 / 도구 / 작업·대화 / 웹 감독 / 목표 / 설정을 같은 주소의 hash로 탐색한다. 모바일 하단 메뉴와 PC 왼쪽 메뉴의 순서는 동일하며 뒤로 가기로 복귀한다. 계정 아래에 차단 정책·경고 설정을 둔다. 초기화권·RDC·복구·계정 순서 등은 도구 검색으로 찾는다. 화면 설정과 휴대폰 연결은 설정 안에 둔다.
변경은 기존 preview → 단회 confirm → 원래 operation 결과 조회를 유지한다. 화면 캐시 갱신과 사용량 새 조회를 구분한다. 편집 중인 계정 입력·정책을 캐시 갱신으로 덮지 않는다. 인증 실패는 연결 안내·재조회만 제공하며 권한 우회를 추가하지 않는다.

## 계정에서 도구로 바로 이동
계정 상단에 순서·정책·경고·전체 도구 바로가기를 둔다. 계정별 초기화권 조회·사용은 정확한 계정을 유지해 해당 도구로 이동한다. 도구는 분류 필터와 펼침 상태를 유지하며 웹 기능·PC 실행 요청·PC 직접 사용을 구분한다. PC 창 열기 요청을 폰 내장 화면으로 표현하지 않는다. 전체 서비스 진단은 명시 진단 기능에서만 수행한다.
