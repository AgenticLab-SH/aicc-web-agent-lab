# 미루 오늘·원형 시간표

Android My Sunrise의 ‘오늘’ 화면에 이식할 수 있도록 미루의 루틴 디자인을 완성하세요. 기존 색상·큰 둥근 카드·시간순 목록을 살려 주세요. 첫 화면에서 오늘 일정의 현재 위치와 다음 루틴을 알 수 있게 만드세요.

1. 시간순 목록과 원형 하루 시간표를 같은 데이터로 구현하세요. 완료 여부도 두 보기에서 동기화하세요. 24시간 위치, 겹치는 일정, 날짜 경계를 넘는 일정, 여러 항목의 긴 이름을 처리하세요. 원형 조작이 어려운 상황에서도 목록에서 같은 정보를 읽고 조작할 수 있어야 합니다.
2. 루틴 추가·수정·삭제·완료를 임시 브라우저 저장소로 검증하세요. 저장 후 새로고침, 날짜가 바뀐 뒤 완료 리셋, 비어 있는 날의 첫 행동을 확인하세요. 일정 모델의 `id`, `title`, `start`, `end`를 유지하고 필요한 필드와 규칙은 인수 문서에 적으세요.
3. 360px와 768px, 키보드, 확대 상태에서 확인하세요. 인수 문서에 색상·간격·원형 위치 계산·탭 동작과 Android Compose에서 대응할 화면을 정리하세요.

작업 범위는 `miru-routine/`입니다. 기상 알람, 조명 제어, 결제, 캘린더 연동과 서버 동기화는 이 프리뷰 범위 밖입니다. 완료 ZIP에는 실제 실행 근거와 검증하지 못한 항목도 넣으세요.
