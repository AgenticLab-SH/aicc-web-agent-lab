  1. PC에서 독립 웹 관리 화면의 설정 → 기기 관리를 엽니다.

      조회 전

      조회 전

      협업 상태 조회로 새로 읽습니다. 문서 인수는 대화 발신이나 자동 실행을 시작하지 않습니다.

      일반 Chat GPT 큐

      역할별 협업

      조회 전

      큐·목표 조정은 Queue & Goal에서, 계정 전환은 계정·한도에서 합니다. 원장 기록과 실제 작업 완료는 별개이며, Codex 내장 goal 제어는 지원 확인이 필요합니다.

      전체 목표 원장

      AICC에 기록한 목표의 상태를 PC와 휴대폰에서 읽습니다. 상태는 원장을 갱신한 시점의 기록이며 실제 실행 상태와 다를 수 있습니다.

      조회 전

      읽기 전용입니다. 소유자 확인 표시는 목표 완료와 별개이며,Codex 내장 goal과 대화 큐의 추적 상태는 변경하지 않습니다.

      선택 대화 큐

      선택한 대화만 등록하고 켭니다. 끄기는 다음 자동 재개만 중지합니다. 현재 작업과 결과가 불명인 요청은 보존됩니다.

      승인된 에이전트는 공식 도구로 기존 Desktop 대화에 작업을 전달할 수 있습니다. 이 화면의 Desktop 켜기는 큐 선택이며, 로컬 감시기의 무인 전달은 아직 연결되지 않았습니다. 한도 회복만으로 자동 재개되지는 않습니다. CLI 대화도 등록만으로 자동재개가 보장되지 않습니다. 아래에서 실행기 정비·전달 미결·재개 확인 상태를 확인하세요.

      조회 전

      OCX 계정과 한도

      조회 전 · 계정 선택과 한도는 확인한 시각의 값입니다.

      계정 사용·일시중지는 트레이의 기존 신원 확인과 실행기를 사용합니다. 초기화권과 복구·RDC 기능은 공통 제어 도구에서 지원 상태를 확인하세요.

      웹 대화 선택

      조회 전 · 읽은 뒤 편집할 수 있습니다.

      등록된 CDP 계정의 정확한 원래 대화 URL을 선택합니다. 응답만 중지·재개하면 외부 작업 결과는 UNKNOWN으로 남습니다. 일반 Chrome 확장 연결의 자동 감시는 지원되지 않습니다.

      대화 간 전달 승인

      감시 켜짐과 별개인 승인입니다. 선택 발신 대화의 완료 응답에서 허용된 입력만 읽어, 정확한 틀로 지정 수신 대화에 한 번 전달합니다. 전체 감독기가 꺼져 있으면 전달하지 않습니다.

      공통 제어 도구

      Windows 트레이와 AICC 앱에서 사용하는 도구입니다. PC 전용 작업은 카드에 표시된 Windows 메뉴에서 진행하세요.

      계정·한도공통 제어 도구협업·인계함웹 감독대화 재개 설정지침·스킬 관리관제 실행

      변경 처리 결과
      시간 초과나 연결 끊김은 미실행 증거가 아닙니다. 원래 요청을 다시 보내지 말고 이 결과를 조회하세요.
      
  
      도움말과 실제 재개
      공통 제어 도구에서 전체 기능과 지원 상태를 확인할 수 있습니다. PC 창 열기는 PC에서 실행되며 휴대폰에 그 창을 표시하는 기능은 아닙니다. 로그인·PC 전용 표시 기능은 해당 항목의 안내를 따르세요.
      Desktop 큐는 공식 도구가 제공된 별도 에이전트에게 인계합니다. 로컬 감시기가 이 도구를 무인 호출하는 연결은 아직 없습니다. 이 화면에서 켜기만 해도 자동 발신된다고 보장하지 않습니다.
      1. 선택한 정확한 대화와 기존 승인 작업을 Queue에서 읽습니다.
      2. 별도 발신자가 공식 대화 조회로 현재 idle·작업 폴더·turn을 확인하고, 실제 실행 경로·한도·보류·불명 시도를 확인합니다.
      3. Claim을 한 번 받은 뒤 해당 marker로 공식 메시지를 한 번 전송합니다.
      4. 실제 전송 성공 응답에만 ACK를 남기고, marker와 다른 새 turn이 결속됐을 때 Observe를 기록합니다.
      자기 자신에게 발신하지 않습니다. 정상 생성 중이면 기다립니다. 사용자 중지·결과 불명·내장 goal의 보류는 자동 해제하지 않습니다. 큐 추적 종료는 내장 goal 재개나 전체 업무 완료가 아닙니다.
