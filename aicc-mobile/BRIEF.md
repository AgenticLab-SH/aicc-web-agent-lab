# AICC 모바일 홈·내 앱

폰에서 첫 5초 안에 내가 쓰는 앱을 찾고 실행하거나, 설치·업데이트 상태를 판단할 수 있게 만드세요. 현재 화면은 정보 구조를 보여주는 실행형 출발점입니다.

1. 상단에 데이터 업데이트 시각을 표시하세요. 홈에서 자주 쓰는 앱과 전체 개발 현황으로 한 번에 이동하게 하세요. 전체 현황은 이 작업의 탐색 대상이며 자세한 보고서 디자인은 범위 밖입니다.
2. 내 앱 목록에 검색, 상태 필터, 상태별 다음 행동을 넣으세요. 웹 열기, 설치 가능, 업데이트 가능, PC 전용, 주소 미등록, 사용 종료를 구분하세요. 기존 앱을 대신하는 합성 예시 한 개로 열기 → 설치 안내 → 업데이트 후 표시 변화까지 보여 주세요. `data.mjs`의 ID와 상태값을 유지하고, 추가 데이터가 필요하면 합성 값만 쓰세요.
3. 목록이 비었거나 늦게 오거나 조회가 실패하면 원인과 다음 행동을 보여 주세요. 조회 실패 뒤에는 이전 목록을 보존하는 흐름을 제시하세요. 앱이 설치됐는지 운영상 확인할 수 없는 경우 안내를 보여 주세요.
4. 글이 적어도 구분되는 화면을 만드세요. 상태를 색만으로 표현하지 말고, 360px 너비·큰 글자·키보드에서 핵심 작업을 확인하세요. 768px와 데스크톱도 확인하고 실행한 검사만 남겨 주세요.

작업 범위는 `aicc-mobile/`입니다. 기존 운영 화면 인수를 위해 현재 HTML/CSS/JS의 구조를 유지하거나, 바뀐 화면과 상태의 대응표를 `HANDOFF.md`에 적어 주세요. 상태 확인과 설치 동작은 프리뷰 안에서 시뮬레이션합니다. 공개 배포·외부 통신·실제 설치는 필요하지 않습니다.
