# OCX quota observation interface

AICC projects observations from the registered provider. The portable contract distinguishes short and long windows, stale data, disabled policy, unknown outcomes, and admitted execution. Installing the owner-specific observer and account routing needs its own authority and is outside this preview.

The public preview uses only deterministic sample quota responses. It does not start a watcher, access a remote host, read saved login files, or dispatch account changes. Use /mobile.html#accounts for the mock result and the project model-adapter schemas for integration shape.
